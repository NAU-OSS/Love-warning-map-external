# Global Love Warning Map (全球恋爱避雷地图)

An interactive 3D global web visualization tool that allows users to mark, view, and explore relationship warnings and stories around the globe. Built using 3D web technologies.

## Features
- **3D Interactive Globe**: Rendered with Globe.gl and Three.js for immersive exploration.
- **Global Data Markers**: Interactive arc and pin overlays showing geographic relationship data.
- **Responsive Web UI**: Accessible across desktop and mobile browsers.

## Tech Stack
- HTML5 / JavaScript / CSS3
- [Globe.gl](https://globe.gl/)
- [Three.js](https://threejs.org/)
